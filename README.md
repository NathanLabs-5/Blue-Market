# Blue-Market
Java e-commerce system featuring account management, shopping cart, orders and OOP principles.

## Funcionalidades

- Cadastro e login de clientes
- Conta de gerente
- Gerenciamento de produtos
- Depósito e consulta de saldo
- Carrinho de compras
- Finalização de compras
- Histórico de pedidos (em desenvolvimento)

## Tecnologias

- Java
- IntelliJ IDEA
- Git
- GitHub
